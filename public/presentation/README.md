Screenshots and recordings the deck shows in a phone frame when it cannot run the thing live.

- `whatsapp-onboarding.mp4` — the WhatsApp onboarding conversation, recorded on a phone and exported at **2× speed** (116s of real conversation in 58s). 384×832, H.264, ~700 kbps so it streams on venue wifi. It autoplays muted and loops. The slide's caption says it is sped up; keep that true if you re-cut it.
- `whatsapp-onboarding.webp` — the still from that same conversation. It is the video's poster, so the frame shows the chat instead of a black rectangle while the file loads, and it is what a slide gets if it asks for `image` without a `video`.

Everything else on the feature slides is the running app in an iframe, so it never goes stale.
